# 专家模式

专家模式面向复杂业务场景，通过多智能体协作高质量完成任务。

在**任务模式**中，点击「定制你的 Agent 专家/团队」即可开始创建专家。

---

## 5.1 什么是专家模式？

面对复杂任务，Soulprout 不会让单个 AI 单打独斗，而是：

1. **分析任务**：理解复杂度与所需能力  
2. **组建团队**：为子任务匹配专门智能体  
3. **并行协作**：多个专家同时工作  
4. **统一整合**：主智能体汇总输出完整结果  

### 专家模式 vs 任务模式

| 对比项 | 任务模式 | 专家模式 |
|---|---|---|
| **适合任务** | 简单问答、单步骤任务 | 复杂项目、多步骤业务流程 |
| **工作方式** | 单个 AI 处理 | 多个 AI 并行协作 |
| **执行效率** | 串行处理 | 并行处理 |
| **结果质量** | 依赖单一 AI 能力 | 各取所长，综合优化 |
| **透明度** | 过程相对简单 | Plan / Tools / SubAgents 全程可见 |
| **可复用性** | 一次性 | 专家团队永久保存，可持续迭代 |

## 5.2 5 分钟组建专家团队

以「基金筛选助手」为例：

#### 第一步：描述需求

```
我要做一个短期基金的筛选助手，帮我筛选出近期表现好的基金。
```

#### 第二步：交互确认细节

Soulprout 先确认关键细节（周期、行业、指标、输出格式等），对齐后再规划——从源头避免答非所问。

#### 第三步：AI 自动规划专家团队

| 角色 | 职责 | 配置 |
|---|---|---|
| **主智能体** 基金筛选调度中心 | 统筹流程，整合输出 | 强推理模型 |
| **子智能体1** 市场热点侦查员 | 搜索政策与行业热点 | web_search |
| **子智能体2** 基金数据猎手 | 获取基金信息与表现数据 | 金融数据工具 |
| **子智能体3** 短期动量分析师 | 分析近期走势与动量 | 数据分析工具 |
| **子智能体4** 综合评估员 | 综合给出推荐 | 强综合分析模型 |

#### 第四步：确认并生成

确认后自动配置模型、工具、提示词与调用关系，并保存到专家库。全程对话完成，无需写代码。

#### 第五步：立即使用

在专家库中选择主智能体，直接下达任务；主智能体调度各子智能体并行工作并输出结果。

## 5.3 专家团队的运作原理

```
用户
  ↓ 提出需求
主智能体（调度中心）
  ↓ 任务分解
┌─────────┬─────────┬─────────┐
│ 子智能体1 │ 子智能体2 │ 子智能体3 │
│ 并行执行  │ 并行执行  │ 并行执行  │
└─────────┴─────────┴─────────┘
  ↓ 结果汇总
主智能体（整合输出）
  ↓ 最终报告
用户
```

- **主智能体**：理解全貌、分解任务、把控质量，不是简单传话  
- **子智能体**：独立模型与工具配置，并行执行、互不干扰  
- **全程透明**：右侧可查看各子智能体状态与工具调用，可随时干预  

---

## 5.4 自定义你的专家团队

自动生成的团队可随时在专家库中编辑：

| 参数 | 建议 |
|---|---|
| **模型选型** | 推理 / 创意 / 轻量按需选择 |
| **系统提示词** | 细化角色、SOP 与输出规范 |
| **工具 / 知识库 / 技能** | 精确绑定，限定能力边界 |
| **子智能体** | 增减成员，调整团队结构 |

专家团队永久保存在专家库，随时调用、持续迭代。
