# 快速上手

Soulprout 提供三种核心用法，覆盖日常陪伴到专业办公。

---

## 2.1 灵芽模式

灵芽模式是 Soulprout 的完整体，专为**长期陪伴与持续积累**设计。

- **记忆**：主动记住你的偏好、习惯、个人信息和工作风格，越用越懂你
- **上下文压缩**：长对话自动压缩历史，始终保持高效的上下文窗口，不因对话过长而退化
- **多端触达**：网页 / 桌面客户端，以及微信、飞书、企业微信、小爱音箱、Rokid AI 眼镜等渠道，随时随地接入
- **个性化角色**：你可以为它定义名字、性格和说话风格，让它真正成为你的专属助理

---

## 2.2 任务模式

任务模式用于**专注完成一个特定任务**，不受其他对话上下文干扰。

每次新建任务都是独立会话：历史记忆、其他任务里的杂讯都不会带进来，Agent 只盯着当前这件事做到底。适合调研、写报告、改代码、做方案等需要干净上下文的工作。

---

## 2.3 选择专家

专家模式面向复杂业务与专业场景，通过专家库驱动多智能体协作完成特定高质量任务。点击「专家模式」，根据你的需求交互式创建专家，创建后选择指定专家开启任务和对话。
