# 四大功能库

四大功能库是 Soulprout 区别于普通 AI 工具的能力基础。

---

## 3.1 专家库（Agents）

用于**创建、管理和复用 AI 智能体**。

### 智能体的构成要素

| 参数 | 说明 |
|---|---|
| **类型** | 主智能体（统筹调度）/ 子智能体（专注子任务） |
| **模型** | 为任务特性选择最合适的 AI 模型 |
| **系统提示词** | 定义角色、能力、工作流程和输出规范 |
| **工具** | 绑定该智能体可以使用的工具 |
| **知识库** | 绑定专属的参考资料库 |
| **技能** | 加载特定的技能包，赋予专业能力 |
| **子智能体** | 主智能体可配置要调度的下属子智能体 |

### 主智能体 vs 子智能体

**子智能体**：专注某个具体环节的专员，例如「数据搜集员」「文案撰写员」。  
**主智能体**：统筹调度的项目经理，负责任务分解、调度与结果整合。

### 如何创建智能体？

**方式一：通过专家模式自动生成（推荐）**  
描述业务需求 → 交互确认细节 → 自动规划团队并保存到专家库。

**方式二：手动创建**  
点击「+」新建，填写名称、提示词，配置模型、工具、知识库、技能后保存。

## 3.2 知识库（Knowledges）

**资料管理中心**，适合海量文档长期复用。

### 知识库 vs 直接上传文件

| 场景 | 推荐方式 |
|---|---|
| 资料多且杂，只需检索相关片段 | 知识库 |
| 资料少（1–3 份），需要 AI 完整理解全文 | 直接上传文件 |

### 双模式检索

| 模式 | 适用场景 |
|---|---|
| **RAG 快速检索** | 简单信息查询、快速问答 |
| **AI 知识库检索智能体** | 复杂需求、综合分析，深度挖掘资料 |

---

## 3.3 工具库（Tools）

赋予智能体「动手做事」的能力。常见能力包括：

- **文件**：读写、编辑文档与代码，识别图片
- **执行**：在工作区运行 Shell / Python / Node 等命令
- **联网**：搜索与抓取网页
- **协作**：创建专家、召唤子智能体、蓝图规划
- **记忆与知识库**：记忆读写、知识库检索与管理
- **技能与上下文**：加载技能、压缩或清除对话上下文
- **交互**：向你批量提问以确认细节

通常无需手动选工具，Soulprout 会按任务自动调用；创建智能体时也可精确绑定工具以限定能力边界。

---

## 3.4 技能库（Skills）

Skill 是可复用的专业能力包（脚本、工作流、最佳实践等）。加载后，智能体即可按该领域规范执行，无需每次从零描述流程。

系统内置约 **60** 种技能，覆盖文档、数据分析、调研、营销、教学、开发等常见场景；同时支持**手动上传个人技能**，自定义能力可直接绑定到智能体使用（个人技能优先于系统技能）。
