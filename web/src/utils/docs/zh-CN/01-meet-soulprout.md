# 1. 认识 Soulprout

## 简介

**不需要懂技术**：网站开箱即用的个人 Agent 助理。  
**多端互联**：用微信聊天，戴 AR 眼镜对话，接入小爱音箱。  
**替你思考**：无需纠结于精准的指令表达，AI 会引导你说出完整想法。  
**专业工作能力**：把你的日常工作“训练”成专家。

直接体验（无需本地部署）：[https://www.soulprout.com](https://www.soulprout.com)

## 核心能力

1. **Harness 工程能力**：拥有用户个性化、Agent 个性化、记忆系统、上下文压缩、工具、技能、蓝图规划等能力。
2. **AI 知识库**：面向行业/领域海量资料场景，可将海量资料打包成一个知识库，具备向量检索与 Agent 检索能力。
3. **专家库**：面向特定领域复杂工作流，零代码、交互式对话将流程转为 Agent 流程，自动匹配工具、技能、知识库、子专家，一次创建即可永久复用。
4. **灵芽模式**：面向 C 端用户，保存用户与 Agent 的个性化特征及记忆，越用越懂你；也可调用已有专家，让个人助理监督 AI 干活。
5. **任务模式**：随时创建新的任务对话，让 Agent 专心执行一件事。
6. **多平台集成**：灵芽模式支持接入微信、飞书、企业微信、小爱音箱、AI 眼镜等渠道。
7. **四大功能库**：工具库、技能库、知识库、专家库相互配合，覆盖 Agent 应有能力。
8. **PC 和 SaaS 部署**：支持个人在 PC 上私有部署，也支持企业以多用户 SaaS 方式部署。
