# Quick Start

Soulprout offers three core ways to work — from everyday companionship to professional workflows.

---

## 2.1 Soul Mode

Soul mode is the full Soulprout experience, built for **long-term companionship and continuous learning**.

- **Memory**: Remembers your preferences, habits, personal info, and work style — and gets better over time
- **Context compression**: Long chats are compressed automatically so the context window stays efficient
- **Multi-channel access**: Web / desktop client, plus WeChat, Feishu, WeCom, Xiao Ai speakers, Rokid AI glasses, and more
- **Personalized persona**: Give it a name, personality, and speaking style so it feels like *your* assistant

---

## 2.2 Task Mode

Task mode is for **finishing one specific job** without interference from other conversation context.

Each new task is an independent session: history and noise from other tasks stay out. The agent stays focused on the current job. Ideal for research, reports, coding, proposals, and anything that needs a clean context.

---

## 2.3 Choose an Expert

Expert mode is for complex business and professional scenarios. An expert library drives multi-agent collaboration for high-quality work. Click **Expert mode**, create an expert interactively from your needs, then select that expert to start tasks and conversations.
