# 1. Meet Soulprout

## Introduction

**No technical background needed**: A personal agent assistant that works out of the box in the browser.  
**Multi-device connectivity**: Chat on WeChat, talk through AR glasses, connect Xiao Ai speakers.  
**Thinks with you**: No need to craft perfect prompts — the AI guides you to express your full idea.  
**Professional work capacity**: Train your everyday work into reusable experts.

Try it now (no local setup): [https://www.soulprout.com](https://www.soulprout.com)

## Core Capabilities

1. **Harness engineering**: User personalization, agent personalization, memory, context compression, tools, skills, blueprint planning, and more.
2. **AI knowledge base**: Package large volumes of domain materials into a single knowledge base with vector retrieval and agent-driven retrieval.
3. **Expert library**: Turn complex domain workflows into agent workflows through zero-code, interactive dialogue. Automatically matches tools, skills, knowledge bases, and sub-experts. Create once, reuse forever.
4. **Soul mode**: Persists user and agent personalization plus memories — so your agent understands you better over time. Invoke existing experts and let your personal assistant supervise AI work.
5. **Task mode**: Start a new task conversation anytime and let the agent focus on a single job.
6. **Multi-platform integration**: Soul mode connects to WeChat, Feishu, WeCom, Xiao Ai speakers, AI glasses, and more.
7. **Four integrated libraries**: Tools, skills, knowledge bases, and experts work together to cover what an agent should have.
8. **PC and SaaS deployment**: Run privately on your own PC, or deploy as multi-user SaaS for a team.
