# Open Source & Private Deployment

Soulprout is **fully open source under the MIT license** — free to use, modify, and distribute. Two deployment modes cover personal users through enterprise teams.

---

## 6.1 MIT Open Source

Under MIT you can:

- **Use freely**: Individuals, teams, and companies — free of charge
- **Modify freely**: Change the code and add features for your needs
- **Distribute freely**: Build your own products on Soulprout
- **No commercial lock-in**: Commercial use is free; no license fee

Source: see the project README

Openness makes better products. Issues and PRs are welcome — let’s improve Soulprout together.

## 6.2 Two Deployment Modes

### Mode 1: Personal server

Similar to Openclaw-style local deploy — **serves only your devices and account**.

**Best for**: Individual developers, tinkerers, privacy-conscious users

**Strengths**:
- Data stays local; no third-party servers
- Direct access to local files and services
- Bring your own model API keys
- Full control of the runtime; extend anytime

**How**: Clone → configure env → start services → open in browser

---

### Mode 2: Enterprise SaaS

Deploy Soulprout on **your company servers** as an internal Agent platform for the team or department.

**Best for**: Companies that need internal system integration, centralized AI governance, or vertical industry use

**Strengths**:

| Capability | Description |
|---|---|
| **Internal data** | Connect DBs, APIs, and business systems so agents work on real data |
| **Brand customization** | Your logo and VI — employees see “our company platform” |
| **Security & compliance** | Data stays on the intranet (finance, healthcare, government, etc.) |
| **Deep tool customization** | Internal MCP tools for ERP / OA / CRM |
| **Custom skills** | Package SOPs, jargon, and norms as Skills |
| **Multi-user management** | Accounts, permissions, usage monitoring |

**In short**: Private Soulprout = mature platform + internal data + your brand — a productivity engine for vertical domains.

---

## 6.3 Enterprise Deployment Capabilities

### Deep tool customization

Public agents only see the open internet. After private deploy, Soulprout can fully connect to internal systems via MCP:

- **Internal databases**: Query core business data and generate precise reports
- **Company APIs**: Call internal services and run real workflows
- **Business scripts**: Execute your custom logic

**Example**: “Produce a Q2 South China customer renewal analysis in the company template and submit it to the director via approval.”

| | Public agent | Private Soulprout |
|---|---|---|
| **Data** | Can’t access internal sales data | Reads your database |
| **Templates** | Doesn’t know company format | Uses internal doc templates |
| **Approval** | Can’t touch internal systems | Calls OA APIs to submit |
| **Outcome** | “I can’t do that” | “Report submitted; you’ll be notified after approval” |

### Custom skills

Every company has unique workflows, jargon, and norms. Private deploy supports custom Skills:

- Package domain terms and rules so the agent stays professional
- Encode SOPs so tasks follow company process
- New hires can still produce expert-level work with the agent
