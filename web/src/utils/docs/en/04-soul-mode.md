# 4. Soul Mode

Soul mode is the full Soulprout experience: long-term memory, context compression, multi-channel access, and deep collaboration — so AI stays with you as a lasting partner.

---

## 4.1 Core Capabilities

Every channel talks to the **same Soulprout core**. Whether you chat on the web, WeChat, Feishu, WeCom, Xiao Ai, or AI glasses, you’re talking to the *same* assistant — so it can remember preferences, habits, and context from every place you use it.

### Persistent memory

- **User info**: Job, interests, work style, preferences
- **Agent persona**: Name, personality, speaking style
- **Business context**: Important facts can be persisted and recalled next time

### Context compression

When conversations get long, history is compressed automatically: keep what matters, drop the noise. You can also trigger it manually. Long chats stay sharp.

### Multi-channel access

| Channel | Description |
|---|---|
| **Web** | Open the browser and chat |
| **WeChat / Feishu / WeCom** | Talk inside everyday messaging apps |
| **Xiao Ai speaker** | Voice interaction |
| **Rokid AI glasses** | Wearable, always with you |

---

## 4.2 Blueprint Mode

Complex tasks are often vague or incomplete. Ordinary AI jumps straight to execution and drifts off course.

Blueprint mode uses **supervised planning**: the AI helps you clarify your idea first, then acts.

1. **Guided clarification**: Asks about gaps — headcount, budget, preferences, success criteria — to complete your intent  
2. **Generate a blueprint**: A visible plan (steps, dependencies, tools/skills)  
3. **Confirm, then execute**: Work starts only after you’re aligned — fewer wrong answers

This is **“thinks with you”**: you don’t need a perfect prompt; the AI guides you to say the full idea out loud.

---

## 4.3 Human–AI Collaborative Editing

Open AI-generated files in the right-hand file library and edit them directly. Tell Soulprout to continue — it will follow *your* revised version. No copy-paste ping-pong.
